asymmetric-editorial: offset blocks on a visible grid.
- Find the grid: outer margins and the column edges blocks snap to. Reuse those exact x values for every item on a shared edge.
- Each block has its own position and size; there is no centre line. List them top to bottom.
- Mixed type is normal: serif display beside small sans or mono labels. Give each its own font key and size it with that font's cap ratio.
- Thin rules, index numbers and captions add many edges: rules as 1px rects, labels as shared-style lines.
- Images sit in fixed boxes: MEDIA at exact bounds.
- Usual mistakes: aligning blocks that are deliberately offset, dropping rules and captions, undersized serifs.
