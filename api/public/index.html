What happens when you paste

  1. 1

    Check

    62 fixed rules read your HTML. No model is involved, so the same page always gets the same answer. They catch purple gradients, gradient text, glows, side-stripe cards, eyebrow labels, glass blur, emoji icons, filler words and low contrast.

    Free, about half a second

  2. 2

    Redesign

    Claude Sonnet rebuilds the section to clear every finding and tighten the type and layout. Your headline, button labels, colours and fonts stay as they are.

    About 20 seconds, about $0.03

  3. 3

    Check again

    The same rules run on the result, so you see the count before and after instead of taking our word for it. You get plain HTML back.

    Copy it or download it

  4. 4

    Learn

    Redesigns pass through Mubit, a model gateway that keeps the good ones to train Pika's own small model. Untick the box and only metadata is kept.

      API

      Two endpoints. JSON in, JSON out, no key. Send one complete section as an HTML string.

      POST /v1/check

      Runs the 62 rules. Free, no model, about half a second.

      curl -X POST https://pika.example/v1/check \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>..."}'

      Returns findings, slop and quality counts, and brandNotes for rules that only judge your brand's own colours or fonts.

      POST /v1/improve

      Checks, redesigns and checks again. About 20 seconds.

      curl -X POST https://pika.example/v1/improve \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>...", "notes": "keep it calm", "record": false}'

      Returns html, before and after findings, token use and cost. notes is optional, up to 500 characters.

      Is it just a prompt?

      No. The check is a fixed rule set that runs without a model and gives the same answer every time. The model only does the redesign, and the rules then check its work.

      What does it cost?

      Checks are free. Redesigns are free here too, up to five an hour per address and a daily total; each one costs us about $0.03.

      Where does my HTML go?

      Checks stay on this server. Redesigns go to Claude Sonnet through Mubit, which records them to train Pika's model unless you untick the box or send "record": false. Do not send private or personal data.

      What do I get back?

      One plain HTML file with inline CSS and no scripts, yours to use. Previews here run with scripts off and no outside requests. Limit: 40,000 characters in.
