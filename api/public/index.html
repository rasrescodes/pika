What happens when you paste

  1. Check

    The rules read your HTML. No model is involved, so the same page always gets the same findings.

    Free, under a second

  2. Redesign

    Claude Sonnet rebuilds every section to clear the findings and tighten type, layout and rhythm. Your copy, colours and fonts stay.

    About 20 s for a section, 90 s for a page

  3. Check again

    The same rules run on the result, so you see the count before and after instead of taking our word for it.

    Plain HTML back

  4. Learn

    Redesigns pass through Mubit, a model gateway that keeps the good ones to train Pika's own small model.

    Opt out on any request

Whole pages, top to bottom

      API

      Two endpoints. JSON in, JSON out, no key. Send one HTML file as a string.

      POST /v1/check

      Runs the 62 rules. Free, no model, under a second.

      curl -X POST https://pika.example/v1/check \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>..."}'

      Returns findings, slop and quality counts, and brandNotes for rules that only judge your brand's own colours or fonts.

      POST /v1/improve

      Checks, redesigns and checks again. 20 to 120 seconds.

      curl -X POST https://pika.example/v1/improve \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>...", "notes": "keep it calm", "record": false}'

      Returns html, before and after findings, token use and cost. notes is optional, up to 500 characters.

      Is it just a prompt?

      No. The check is a fixed rule set that runs without a model and gives the same answer every time. The model only does the redesign, and the rules then check its work.

      What does it cost?

      Checks are free. Redesigns are free here too, up to five an hour per address and a daily total. Each one costs us about $0.03 for a section and $0.10 to $0.20 for a full page.

      Where does my HTML go?

      Checks stay on this server. Redesigns go to Claude Sonnet through Mubit, which records them to train Pika's model unless you untick the box or send "record": false. Do not send private or personal data.

      What do I get back?

      One HTML file with inline CSS and no scripts, yours to use. It keeps your images and works on desktop and mobile. Previews here run with scripts off.
