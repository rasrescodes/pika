Make your section look designed, not generated.

Paste a hero section. Pika checks it against Impeccable's design rules for free, then redesigns it with craft rules from three open design skills, keeping your words and your colours.

How it works

  1. 1

    Check

    Impeccable's 62 rules read your HTML and flag the AI tells: gradient text, glows, side stripes, eyebrow chips, filler words, low contrast.

    Free · about half a second

  2. 2

    Redesign

    Claude Sonnet redesigns the section with craft rules condensed from three open design skills. Your words, colours and fonts stay; the findings go.

    About 20 seconds · about $0.03

  3. 3

    Check again

    The same rules check the result, so you get the before and after in numbers, not a promise. Copy the HTML or download it.

    Same detector · same rules

  4. 4

    Learn

    Every redesign goes through Mubit, which keeps the good ones to train Pika's own small model, so taste moves out of a long prompt and into the weights.

      Why these rules

      We measured them before shipping them. Same model, same 24 held-out briefs; only the prompt changed between Pika's plain prompt and the skills rules this API uses.

      3.67to0.21

      detector findings per page, about 94% fewer

      6to0

      broken layouts, where text is covered or runs off the frame

      7.32and7.17

      Juror score out of 10, so the clean-up does not cost quality

      Measured on sections Sonnet generated from a brand kit, not on redesigns of existing pages. The Juror is Pika's own model-based critic and the detector is Impeccable's rules; neither is a human jury.

      The API

      Two endpoints, JSON in and out, no key needed. Send one complete section as an HTML string.

      POST /v1/check

      Runs Impeccable's detector. Free, no model involved, about half a second.

      curl -X POST https://pika.example/v1/check \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>..."}'

      Returns findings, slop and quality counts, and brandNotes for rules that only judge your brand's own colours or fonts.

      POST /v1/improve

      Checks, redesigns with the skills rules, and checks again. About 30 to 60 seconds.

      curl -X POST https://pika.example/v1/improve \
  -H 'content-type: application/json' \
  -d '{"html": "<!doctype html>...", "notes": "keep it calm", "record": false}'

      Returns html, before and after findings, token use and cost. notes is optional, up to 500 characters.

      Limits and privacy

      • Up to 40,000 characters of HTML. Five redesigns an hour per address and a daily total; checks are limited only to stop abuse.
      • Redesigns run on Claude Sonnet through Mubit, the model gateway. Mubit records each redesign so Pika's own small model can learn from it. Send "record": false to keep only metadata. Do not send private or personal data.
      • Previews on this page run with scripts off and no outside requests.
